The MIT licence in this repository covers the authors' original code. CC BY 4.0 covers their original research data and question materials. Neither licence overrides third-party rights.

The analyses used the following external question collections. Their verbatim questions and answer explanations are not distributed in this package; use the upstream sources and their terms to obtain them.

| --- | --- | --- |
| MedQA / USMLE | https://github.com/jind11/MedQA | MIT |
| MedMCQA | https://github.com/medmcqa/medmcqa | MIT (`LICENSE.md`) |

| MedXpertQA | https://github.com/TsinghuaC3I/MedXpertQA | MIT |
| MedBullets / ChallengeClinicalQA | https://github.com/HanjieChen/ChallengeClinicalQA | No redistribution licence established for this release |

The package includes answer labels, correctness indicators, confidence estimates and experimental outcomes generated in this study. It does not grant rights to the underlying third-party wording. Human-transcript text is de-identified; some conversations necessarily discuss medical question content.

Python dependencies retain their own licences. The package does not redistribute workstation-specific display profiles.
