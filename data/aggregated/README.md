# Final aggregate results

These are exports of the finalized analyses, included for convenient inspection.

- `table2.csv` and `.md`: setting-level performance, PCS and inferential results. The Markdown contains the denominator and uncertainty definitions.
- `exp4_selection_table.csv` and `.md`: the three interaction categories, valid-answer denominators and participant-clustered comparisons (Supplementary Table S1).
- `group_level_pcs_vs_gain.csv`: 56 anonymous group/model-pair-by-benchmark records used in the predictive analyses; `pcs` and `gain` are percentage points.
- `rerun_pediatric_duos.csv`: additional pediatric model-pair results.

Run the scripts listed in `analysis/build_aggregate_exports.py`, then run that exporter to rebuild these files. These summaries are not interchangeable with pooled individual observations. The underlying de-identified inputs remain in `data/` and `derived_data/`.
